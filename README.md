## 실행·사용 방법

1. [학교 네트워크 루프 장애 대응](cases/network-loop-response.md)에서 현장 문제를 확인합니다.
2. [가계부 운영·백업/복구](cases/our-ledger.md), [자동화 툴킷](cases/automation-toolkit.md), [급식 도구](cases/auto-menu.md)에서 개인 프로젝트를 살펴봅니다.
3. [검증 기록](docs/verification.md)에서 당시 환경·명령·제외 범위를 확인합니다.

공개 샘플은 Node.js 22 이상에서 별도 의존성 설치 없이 실행합니다.

```powershell
npm test
```

### 별도 학습 실습

[IT 운영 미니 실습](labs/README.md)은 이번 작업에서 AI 에이전트가 작성·실행한 학습용 코드입니다. 지원자의 실무 경력이나 본인이 직접 재현한 기술로 간주하지 않습니다.

- 루프백 HTTP 서비스: 정상 응답 → 서비스 중지에 따른 연결 거부 → 재시작 복구
- 합성 자산·계정 데이터: 중복 ID, 퇴직자 활성 계정, 정상 입력 검사

실제 네트워크 설정이나 SaaS 계정을 변경하지 않습니다. DNS·VLAN·상용 Linux 운영을 검증한 실습도 아닙니다. [명령·출력·종료 코드](labs/evidence/execution.log)를 함께 제공합니다.

## 검증과 한계

| 근거 | 확인하는 범위 | 범위 밖 |
| --- | --- | --- |
| [현장 사례](cases/network-loop-response.md) | 이력서에 기재한 수행 업무와 문제 대응 과정 | 기관 내부 구성도·운영 로그·IP·개인정보 |
| [샘플 검증](docs/verification.md) | Node 테스트 파일 1개, 내부 assertion 31개 | 원본 앱 전체·비공개 가계부·배포·외부 서비스 |
| [학습 실습](labs/README.md) | 루프백 HTTP 중지/복구, 합성 자산·계정 데이터 검사 | 지원자의 직접 수행 실무·상용 Linux 운영 실적 |

과거 성공 기록은 해당 날짜·커밋·환경의 결과입니다. AI 에이전트가 실행한 점검과 지원자 본인의 직접 재현·검토를 구분합니다. 각 사례의 기여 범위와 한계는 원문 기록을 기준으로 봅니다.

## 기여와 관련 문서

개인 프로젝트는 **이지섭과 AI 도구의 협업** 결과입니다. 실무 경력, 개인 프로젝트, AI 에이전트가 실행한 점검을 구분하며 [검증 기록](docs/verification.md)에 환경·기여 범위·한계를 표시합니다.

<details>
<summary>AI 협업·실행 주체와 공개 범위</summary>

개인 프로젝트는 이지섭과 AI 도구의 협업 결과물이며, 단독 수작업 개발 또는 상용 운영 성과로 표현하지 않습니다. 공개 코드·테스트는 구현의 근거이고, 모든 설계·구현을 독립적으로 설명할 수 있다는 증명과는 구분합니다.

2026-10-07 채용용 문서 정리와 이번에 추가되는 실행 점검은 AI 에이전트가 수행했습니다. 지원자 본인의 직접 수행 경험은 실무 경력으로 별도 표시하고, 신규 실습 결과는 본인이 직접 검토·재현한 결과와 구분합니다.
