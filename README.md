## IT 실무 경력

### 제이비시스템 | 2026.01~2026.07 · 7개월
공공기관 통합유지보수 업무에서 원내 시스템 보안 운영과 PC 유지보수·사용자 업무환경 지원을 담당했습니다.

### 디오제이 | 2025.09~2025.11 · 3개월
프리랜서로 학교 네트워크 개선 **단기 프로젝트**에 참여했습니다. 네트워크 점검, 장비 설정, 장애 처리와 네트워크 구성 문서 작성을 수행했습니다.

### 네트워크 접속 문제 해결 경험
- **상황:** 서버와 접속할 PC가 서로 다른 공유기에 연결되어 접속 환경 설정이 필요했습니다.
- **조치:** 필요한 포트만 개방하고 TP-Link 공유기의 DDNS 기능을 설정했습니다.
- **결과:** 숫자 IP 대신 도메인 주소로 서버에 접속할 수 있도록 했습니다.
- **공개 범위:** 운영 주소·IP·포트 번호는 공개하지 않습니다.

## 프로젝트 자료

### 1. our-ledger | 자체 호스팅 가계부
**다루는 문제:** 두 사용자가 한 가구의 수입·지출을 기록하고, 연결이 불안정할 때도 기록을 이어가는 흐름입니다.

- **구조:** Kotlin·Spring Boot·Spring Security·JPA·PostgreSQL·Flyway 서버, Jetpack Compose·Room·WorkManager Android 앱.
- **배포·검증 구성:** GitHub Actions의 서버 테스트·bootJar·Docker 빌드, Android 단위 테스트·lint·빌드·에뮬레이터 UI·Room 마이그레이션 검증 단계.
- **복구 구성:** 암호화 백업·복원 검증 스크립트와 운영 문서.
- **범위:** 가계 1개·사용자 2명·원화 기록. 테스트 단계의 존재와 최신 실행 성공은 구분하며, 대규모 운영이나 측정하지 않은 성능 개선을 주장하지 않습니다.

### 2. auto-menu | 브라우저 기반 식단 아이디어 편집기
**다루는 문제:** 주간 식단 아이디어를 편집하고 결과를 내보내거나 백업해 다시 활용하는 흐름입니다.

- **구조:** Next.js·React·TypeScript. 브라우저 로컬 저장, 주간 CSV·PNG 출력, JSON 백업·복원. 서버 데이터베이스는 사용하지 않습니다.
- **검증 대상:** 백업 버전·객체 구조·필드 타입·이름 길이·메뉴 배열 제한과 잘못된 입력 처리.
- **공개 근거:** [검증 코드·합성 테스트](samples/meal-workspace/)는 원본 일부를 데이터셋 없이 분리·변형한 샘플입니다.
- **검증 기록:** 2026-09-15 ES2023+ REPL에서 합성 테스트 31개 통과. Node 모듈 로딩·CI·원본 앱 실행의 검증 결과는 아닙니다. [실행 범위와 한계](samples/meal-workspace/TEST-RESULTS.txt).
- **범위:** 식단 아이디어 편집 도구이며 영양 적합성·알레르기 안전성을 인증하지 않습니다.

### 3. ComfyUI Game Asset Workflows | 오디오 후처리 자동화
**다루는 문제:** 생성한 게임용 오디오의 후처리, 출력 파일과 메타데이터 관리입니다.

- **구현:** Python·FFmpeg 기반 무음 제거, 크로스페이드, 2-pass 음량 정규화, true peak 제어와 OGG 출력.
- **오류 처리:** 출력 후 true peak 재측정·재시도, 파일 충돌 방지, 실패 시 롤백과 메타데이터 기록.
- **공개 근거:** [저장소](https://github.com/jisub-lee-0906/comfyui-game-asset-workflows) · [finalize_audio.py](https://github.com/jisub-lee-0906/comfyui-game-asset-workflows/blob/main/audio_bgm_with_sfx/scripts/finalize_audio.py).
- **범위:** 공개 구현의 설명이며 모든 입력의 음질·처리 성공을 보증하지 않습니다.
