## IT 실무 경력

### 제이비시스템 | 2026.01~2026.07 · 7개월
공공기관 통합유지보수 업무에서 원내 시스템 보안 운영과 PC 유지보수·사용자 업무환경 지원을 담당했습니다.

### 디오제이 | 2025.09~2025.11 · 3개월
학교 네트워크 개선 단기 프로젝트에 프리랜서로 참여했습니다. 네트워크 점검, 장비 설정, 장애 처리와 네트워크 구성 문서 작성을 수행했습니다.

## 현장 장애 대응

학교 네트워크 개선 작업에서 스위치 교체 중 루프 장애가 발생했습니다. 루프가 발생하는 스위치를 찾아 네트워크에서 분리해 장애를 해소했습니다.

현장 업무에서는 사용자 문의·불만 응대도 경험했습니다.

## 직접 설정한 서버 접속 환경

- **상황:** 서버와 접속할 PC가 서로 다른 공유기에 연결돼 있어 접속 환경 설정이 필요했습니다.
- **조치:** 공유기에서 필요한 포트만 개방하고, TP-Link DDNS를 설정했습니다.
- **결과:** 해당 PC에서 숫자 IP 대신 도메인 주소로 서버에 접속할 수 있었습니다.
