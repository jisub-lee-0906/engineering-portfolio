## 검증·공개 범위

공개 샘플의 **31개 합성 테스트는 ES2023+ REPL 실행 기록**입니다. Node 모듈 로딩·CI·원본 앱 전체를 검증한 결과가 아닙니다. 비공개 원본과 로그를 외부에서 직접 열 수 없는 사례는 문서 요약으로 제공합니다.

<details>
<summary>검증 기준과 공개 제한 자세히 보기</summary>

- 실행 기록은 날짜·대상 커밋·실행 범위가 확인된 결과입니다. 과거 성공을 최신 버전의 성공으로 바꾸어 쓰지 않습니다.

- 테스트 정의와 테스트 통과는 구분합니다. 배포 완료 역시 테스트 통과를 의미하지 않습니다.

- 원본 프로젝트의 운영 주소·IP·포트·자격증명·개인 데이터와 권리 검토가 필요한 에셋·데이터셋은 공개하지 않습니다. 이 문서는 원본 전체의 공개 허가가 아닙니다.
- ComfyUI의 모델/노드·생성물 권리, 기술적 실행 성공과 시각·청각 품질은 별도로 판단합니다.
