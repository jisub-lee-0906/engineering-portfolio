이 저장소의 기존 샘플 테스트는 의존성 설치 없이 Node.js 22 이상에서 실행합니다.

```powershell
npm test
```

Node 테스트 파일 1개 통과와 파일 내부 assertion 31개 통과는 서로 다른 집계입니다. 이 명령은 원본 앱 전체, 비공개 가계부, 배포 또는 외부 서비스를 검증하지 않습니다.

## 개발 방식과 기여 범위

개인 프로젝트는 이지섭과 AI 도구의 협업 결과물이며, 단독 수작업 개발 또는 상용 운영 성과로 표현하지 않습니다. 공개 코드·테스트는 구현의 근거이고, 모든 설계·구현을 독립적으로 설명할 수 있다는 증명과는 구분합니다.
