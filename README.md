# 이지섭 | IT 운영·서비스 배포·자동화

**IT 실무 10개월** · 공공기관 보안 운영·PC 유지보수 7개월 · 학교 네트워크 개선사업 3개월

시스템 운영·네트워크 유지보수 직무를 중심으로 지원합니다. 실무 경험과 별도로, AI 도구와 협업한 프로젝트에서 서비스 동기화·배포·복구와 반복 작업 자동화를 다뤘습니다.

## IT 실무 경력

### 제이비시스템 | 2026.01~2026.07 · 7개월
공공기관 통합유지보수 업무에서 원내 시스템 보안 운영과 PC 유지보수·사용자 업무환경 지원을 담당했습니다.

### 디오제이 | 2025.09~2025.11 · 3개월
프리랜서로 학교 네트워크 개선 단기 프로젝트에 참여했습니다. 네트워크 점검, 장비 설정, 장애 처리와 네트워크 구성 문서 작성을 수행했습니다.

### 직접 겪은 네트워크 접속 문제
서버와 접속할 PC가 서로 다른 공유기에 연결되어 접속 환경 설정이 필요했습니다. 필요한 포트만 개방하고 TP-Link 공유기의 DDNS를 설정해 숫자 IP 대신 도메인으로 서버에 접속할 수 있도록 했습니다. 운영 주소·IP·포트 번호는 공개하지 않습니다.

## 검증 상태를 읽는 기준

- **실행 기록:** 날짜·대상 커밋·실행 범위가 확인된 결과만 적습니다. 과거 성공을 최신 버전의 성공으로 바꾸어 쓰지 않습니다.
- **구현 확인:** 소스에 처리 로직이 있다는 뜻이며 실제 운영 성과나 모든 입력의 성공을 의미하지 않습니다.
- **테스트 정의:** 검증 코드가 있다는 뜻입니다. 통과 기록이 없으면 통과했다고 쓰지 않습니다.

공개 샘플의 31개 합성 테스트는 ES2023+ REPL 실행 기록이며 Node 모듈 로딩·CI·원본 앱의 검증 결과가 아닙니다. 우리 가계부의 배포 기록은 큐 등록까지 확인되며 현재 서비스 정상 운영을 보증하지 않습니다.
