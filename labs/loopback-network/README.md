# 루프백 네트워크 문제 해결 실습

## 성격

프로덕션 경험이 아닌 작은 교육용 데모입니다. AI 에이전트가 작성하고 실행했으며, 사용자의 검증된 기술이나 고용 경력을 의미하지 않습니다.

## 목적과 구성

Node.js HTTP 서버를 `127.0.0.1`의 OS 할당 임시 포트(`port: 0`)에만 바인딩합니다.

```text
[HTTP 클라이언트]
       |
       v
127.0.0.1:<ephemeral>/health
       |
       +-- 실행 중: 200 {"status":"ok"}
       +-- 중지됨: ECONNREFUSED
       +-- 같은 포트 재시작: 200 복구
```

## 예상 대 실제

| 단계 | 예상 | 실제 |
|---|---|---|
| 정상 | `/health`가 HTTP 200과 `{"status":"ok"}` 반환 | PASS |
| 서비스 중지 | 새 연결이 `ECONNREFUSED` | PASS |
| 재시작 | 같은 루프백 포트에서 HTTP 200 복구 | PASS |

[실행 코드](run.cjs)와 [실행 로그](../evidence/execution.log)에서 정확한 출력과 종료 코드를 확인할 수 있습니다. 리스너는 `finally`에서 닫습니다. 예상과 다르면 단언 실패로 종료 코드가 0이 아닙니다.

## 한계

- DNS를 조회하거나 장애로 에뮬레이션하지 않습니다.
- VLAN, 라우팅, 방화벽, 패킷 손실, 지연을 에뮬레이션하지 않습니다.
- OS 또는 네트워크 설정을 변경하지 않습니다.
- 외부 네트워크와 외부 대상 IP를 사용하지 않습니다.
- 단일 프로세스의 루프백 동작만 보여 주므로 실제 분산 환경 장애 대응 경험을 나타내지 않습니다.
