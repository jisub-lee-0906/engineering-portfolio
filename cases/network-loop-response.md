# 학교 네트워크 루프 장애 대응

**구분: 실무 경험 / 디오제이 단기 프리랜서 / 2025.09~2025.11**

## 환경과 수행 범위

강남·서초 초·중·고 네트워크 개선사업에 참여했습니다. 현장 스위치 위치와 장비 간 연결 관계를 확인해 네트워크 구성도를 작성하고, 네트워크 점검·장비 설정·교체 작업을 수행했습니다.

## 상황 → 행동 → 결과

| 단계 | 확인된 내용 |
| --- | --- |
| 상황 | 스위치 교체 작업 중 네트워크 루프 장애 발생 |
| 행동 | 루프가 발생하는 스위치를 찾아 네트워크에서 분리 |
| 결과 | 문제 장비 분리로 장애 해소 |

핵심은 문제 장비를 찾아 분리한 현장 대응 경험입니다. 장비 분리에 의한 장애 해소와 근본 원인 제거·재발 방지까지 완료한 것은 구분합니다.

## 공개 근거와 제한

이 문서는 이력서에 기재한 경험을 2026-10-07 AI 에이전트가 재구성한 경력 사례입니다. 독립적인 운영 로그 검증 또는 실험 결과가 아닙니다.

현재 공개 자료에는 다음 정보가 없습니다. 따라서 임의로 채우지 않습니다.

- 장비 제조사·모델, 담당 학교·장비 수
- 문제 장비를 식별한 구체적인 명령·관찰 근거
- 장애 지속 시간·복구 시간·영향 사용자 수
- 정상화 확인 방법, STP 설정 또는 재발 방지 조치

실제 기관의 네트워크 구성도, 내부 주소, 장비 설정과 보안 정책은 포함하지 않습니다. 학습용 네트워크 실습은 별도로 표시하며 당시 현장을 재현했다고 주장하지 않습니다.
