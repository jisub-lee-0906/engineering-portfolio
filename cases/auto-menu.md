# 오늘의 급식 | 저장 데이터 검증·백업·내보내기

## 프로젝트 요약
- **원본 프로젝트:** auto-menu
- **목적:** 식단 아이디어를 정리하고 날짜별 주간표를 편집하는 브라우저 기반 도구.
- **역할 구분:** 개발은 이지섭과 AI 도구의 협업, 메뉴 1차 검수는 협업자가 담당했습니다.
- **기술:** Next.js, React, TypeScript, Playwright. 계정·서버 DB 없이 브라우저에 저장하는 구조입니다.
- **검토 기준일:** 2026-09-16.

## 어떤 문제를 다루나
로컬 저장값이나 사용자가 불러온 JSON이 잘못되면 편집 중인 상태에 영향을 줄 수 있습니다. 내보내는 CSV도 쉼표·따옴표와 스프레드시트 수식으로 해석되는 입력을 고려해야 합니다.

| 확인한 처리 | 근거 |
| --- | --- |
| 실제 달력 날짜, 메뉴/날짜별 객체 구조, 자료형·길이·개수 제한 검사 | lib/planner.ts |
| 버전 있는 JSON 백업 검사 | lib/planner.ts |
| BOM CSV, 따옴표 이스케이프와 수식 해석 방지 처리 | lib/planner.ts |
| workspace 버전·필드 타입 검사, 제외 이름 중복 제거, 최근 메뉴 이력 관리 | lib/workspace.ts |
| 로직 및 desktop/mobile 편집 화면 테스트 프로젝트 | playwright.config.ts |
